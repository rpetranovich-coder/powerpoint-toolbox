Standardize Font ✦ new
Type any font name (default: Aptos) and click "Apply to Slide". Iterates every shape on the current slide and sets the font name on its text range. Works on text boxes, shapes, titles, and body placeholders. Press Enter or click the button.
Insert Table ✦ new
Set row (R) and column (C) counts — both clamped to sensible limits (R: 1–20, C: 1–10). Inserts a centered table at ~640pt wide. Requires Microsoft 365 current channel (uses addTable API).
Column Guides ✦ new
Choose 2 / 3 / 4 / 5 columns and click Guides. Inserts N+1 thin light-blue vertical lines at the column boundaries within a 40pt margin on each side. All guides are sent to back automatically so they don't block content. Re-running replaces existing guides. Clear removes them all.

For 3 cols on a 960pt slide: guides at 40, 333, 627, 920pt.
